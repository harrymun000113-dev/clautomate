# 수출 제안서 검토기

바이어 국가·품목·거래조건을 입력하면 5대 주의사항(문화·영문·WIIFM/ROI·법규·인코텀즈)을 자동 검토하고,
제안서 덱·오퍼시트·근거 부록·영문 커버 이메일·검토 보고서를 만드는 단일 페이지 웹앱입니다.
빌드 도구나 설치가 필요 없습니다.

## 실행
- 로컬: `index.html`을 브라우저로 엽니다.
- 배포: 정적 사이트라 Vercel에서 이 저장소를 Import하고 기본 설정(Framework Preset: Other, 빌드 명령 없음)으로 Deploy하면 됩니다. PR마다 미리보기 주소가 생기고, `main`에 머지하면 운영 주소에 반영됩니다.

## 파일 구조
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 마크업 (입력 8단계, 검토 패널, 산출물 탭) |
| `style.css` | 디자인. 맨 위 `:root`에 색·폰트 토큰, 다크 모드 토큰 |
| `app.js` | 로직. 아래 구역 주석으로 나뉨 |
| `vercel.json` | Vercel 설정 (확장자 없는 주소) |

`app.js` 구역 (주석 `/* ---------- ... ---------- */`로 검색):
- **reference data**: 국가(`C`), 공휴일(`HOL`, `KRH`), 국가×품목 인증(`CERT`)
- **presets**: 예시 3종(미국·사우디·중국)
- **English lint**: 콩글리시·모호한 표현·유행어·수동태 사전
- **review engine**: `review()` 5개 분류 규칙. 각 항목은 `{cat, st: pass|warn|fail|manual|info, t:제목, p:설명, f:입력칸 id}`
- **outputs**: 덱 순서(`ORDER_DIRECT` / `ORDER_CONTEXT`), 슬라이드·이메일 문안
- **step accordion / events**: 단계 열고 닫기, "고치러 가기" 이동

## AI 에디터(Cursor 등)로 디자인을 고칠 때 프롬프트 예시
```
이 프로젝트는 수출 제안서 자동 검토 웹앱이야. README와 .cursor/rules를 먼저 읽어.
검토 로직(app.js의 review, derive, lint)과 입력 칸 id는 바꾸지 말고, 디자인만 개선해줘.
1) 첫 화면에서 진행 상태(8단계 중 몇 단계 완료, 필수 수정 몇 건)가 한눈에 보이게
2) 검토 패널을 카드형 대시보드로, 필수 수정은 빨간 강조
3) 산출물 탭의 덱 미리보기를 더 실제 슬라이드처럼
4) 라이트/다크 모드와 모바일 폭(400px) 모두 깨지지 않게
```
